# CreatorHub Agent Instructions

Before proposing material project changes, consult the repository's durable project context.

Key files:
- `README.md`
- `docs/THINGS_TO_CONSIDER.md`
- `docs/PROJECT_INTELLIGENCE.md`
- relevant subsystem docs under `docs/`

When the user asks **"what's new with CreatorHub?"** or asks what's new with a CreatorHub subsystem, follow `docs/PROJECT_INTELLIGENCE.md`.

Research and recommendations may be produced without approval. Newly proposed implementation work, algorithm changes, risk changes, or execution changes require explicit user approval.
